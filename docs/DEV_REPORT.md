# 開発レポート：TOMORI YOMU (APP 009)

## 実装内容
- Expo / React Native Web / TypeScript（既存の tomori-pocket-006 と同じ構成：Expo 57、Jest、`expo export`）。
- お話10作品（3年生5話・4年生5話、むずかしさ 1:4話 / 2:4話 / 3:2話 … `src/data/stories.ts`）。すべてオリジナルで、アプリ内データとして保存。外部AI API・サーバー・ログイン・広告・課金なし。
- 画面：お話一覧（学年・むずかしさで絞りこみ）→ 本文 → クイズ（1問ずつ）→ 結果、読書きろく画面（記録の確認・消去・保存場所の注意）。
- クイズ：3択、回答は1問1回。回答直後に ◯/×、正しい答え、解説、本文の根拠を表示。本文の再表示も可能。
- 記録（`src/logic/progress.ts`）：問題ごとの回答結果、学習ずみ、最高・直近の正解数、挑戦回数、日時、途中再開。保存は AsyncStorage（Webでは localStorage）の端末内のみ。壊れた保存データは安全に捨てる。
- デザイン：アイボリー＋薄いオレンジ、本文20px・行間1.9、本文幅600px、読み仮名は小さく表示、◯/×は色だけでなく記号でも区別。
- 一覧サイト連携：`app-info.json`（id 009）、検証スクリプト、CI は tomori-app-lab の `templates/app-template`（未マージのブランチ `claude/modest-goodall-azmqsq` 上）をそのまま使用。

## 文章・問題の品質確認（自動テストで毎回確認）
- 本文は150〜250字（読み仮名を除く）：実測 169〜216字。
- 各問題に `key`（正解のことば）があり、「本文・正解の選択肢・解説」に含まれ、まちがいの選択肢には含まれない → 正解が1つだけで、答えと解説が対応していることを機械的に確認。
- `evidence`（根拠の一文）が本文にそのまま存在。
- 小学5・6年の漢字は使用禁止、小学4年の漢字は3年生向けでは読み仮名つきのみ（テストで検査。実際に不備を検出し修正済み）。
- 正解位置の偏りなし（①②③がそれぞれ6回以上）。
