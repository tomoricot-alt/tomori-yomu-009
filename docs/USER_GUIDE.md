# TOMORI YOMU の使い方

短いお話を読んで、3つのクイズに答えるアプリです。小学3・4年生向けです。

## 1. お話をえらぶ
1. 開くと、お話の一覧が出ます。
2. 「学年」や「むずかしさ」のボタンで、お話をしぼりこめます。
3. 読みたいお話をタップ（クリック）します。

## 2. お話を読む
1. 大きな文字で、お話をゆっくり最後まで読みます。
2. 漢字のよみは、小さく（　）の中に書いてあります。
3. 読み終わったら「クイズにちょうせん！」を押します。

## 3. クイズに答える
1. 1問ずつ、3つの選択肢から1つえらびます。答えは1回だけです。
2. すぐに ◯（正解）か ×（ざんねん）が出ます。
3. 「なぜかというと…」の説明と、「本文のここに書いてあるよ」で、答えのわけを確かめます。
4. わからなくなったら「本文をもう一度見る」で、お話を見ながら考えられます。
5. 3問すべて答えると、けっかが出ます。

## 4. きろくを見る
- 一覧の「くわしく見る」で、学習ずみのお話、正解数、ちょうせんした回数が見られます。
- 学習ずみのお話には ✓ がつきます。何度でもやりなおせます（最高の正解数が残ります）。
- クイズの途中でやめても、同じお話からつづきが始められます。

## ⚠️ 大事なこと
- きろくは**このスマホ／パソコンのブラウザの中だけ**に保存されます。インターネットには送られません。
- ブラウザの「閲覧データの削除」「サイトデータの削除」をすると、**きろくが消えます**。
- 別の端末や別のブラウザでは、同じきろくは見られません。プライベートモードでは、きろくが残らないことがあります。
- 名前・学校名・メールアドレスなどは入力しないでください（求められることもありません）。
- 「きろくを全部けす」ボタンで、自分でもきろくを消せます（もとには戻せません）。
