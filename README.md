# TOMORI YOMU（APP 009）

TOMORI APP LAB 第9号。小学3・4年生が、短いお話を読んで3択クイズに答えながら、読解力を楽しくきたえるアプリです。

- 公開URL: https://tomoricot-alt.github.io/tomori-yomu-009/
- 技術: React Native / Expo / TypeScript / React Native Web
- サーバー・ログイン・広告・課金・外部AI APIは使いません。お話とクイズはアプリ内のデータ（`src/data/stories.ts`）として保存しています。
- 学習記録は端末のブラウザ内（localStorage）だけに保存し、外部へ送信しません。個人情報は取得しません。
- ⚠️ ブラウザのサイトデータを削除すると、記録が消えます。

## 機能

- オリジナルの読み物10作品（1作品150〜250文字。読み仮名を除く）
- 学年（3年生・4年生）とむずかしさ（やさしい／ふつう／ちょっとむずかしい）による分類・絞りこみ
- 読みたいお話を一覧から自由に選択
- 1作品につき3問の3択クイズ（1問ずつ回答）
- 正解・不正解の表示、答えの解説、本文の根拠の表示
- 学習ずみのお話の表示、正解数・挑戦回数・最高記録、クイズの途中再開
- 本を読むような、アイボリーと薄いオレンジのやさしいデザイン（スマホ・PC対応）

テーマ: 友だちとの協力 / 自然や生き物 / 学校生活 / 身近な科学 / 家族とのくらし / 季節の行事

## 開発

```bash
npm ci
npm run web                # 開発サーバー
npm run typecheck          # 型チェック
npm test                   # テスト（データ・判定・記録・保存）
npm run build:web          # 公開用ビルド (dist/)
npm run validate:app-info  # 一覧サイトに登録できる形式か確認
```

## お話を追加・修正するとき

`src/data/stories.ts` に追加します。`npm test` が次を自動で確認します。

- 本文が150〜250文字（読み仮名を除く）
- 3問・3択で、正解番号がある
- 各問題の `key`（正解のことば）が「本文・正解の選択肢・解説」にあり、まちがいの選択肢にはない（＝正解が1つだけで、解説と対応している）
- `evidence`（根拠の一文）が本文にそのまま書かれている
- 小学5・6年の漢字を使っていない（小学4年の漢字は、3年生向けでは読み仮名つきのみ）

## 公開（GitHub Pages）

1. 初回のみ: Settings → Pages → Build and deployment → Source を **GitHub Actions** にする。
2. Pull Request を確認・承認して `main` にマージする。
3. `.github/workflows/deploy.yml` が検証・ビルド・公開を自動で行う（PRでは公開しない）。
4. 公開後、TOMORI APP LAB の一覧サイトに**自動で**追加される（最大1時間程度）。
